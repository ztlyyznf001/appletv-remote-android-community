# 手机与 Apple TV 验收清单

这是待执行清单，不是通过报告。记录源码版本、手机/系统/输入法、Apple TV/tvOS、网络，以及每项通过、失败或未运行。

## 安装与连接

- [ ] 新安装、正确/错误 PIN、取消和重新配对。
- [ ] 保存身份重连；电视身份改变时拒绝冒用。
- [ ] 手动地址成功和错误端点提示。
- [ ] 回到前台有限重连，主动断开不立即连回。
- [ ] 无网络/电视休眠/断线不无限重试、不阻塞 UI。
- [ ] 移除配对后重新配对，不向旧会话发送。

## 遥控与触摸

- [ ] 方向、选择、返回、主屏幕、播放/暂停与电视一致。
- [ ] 单键反馈不让其他按键闪动，快速重复操作不乱序。
- [ ] 滑动/轻点/长按；抬手、取消、旋转、后台均成对释放。
- [ ] 多指、越界、快速切换方向键/触摸板不遗留按下状态。
- [ ] 系统关闭触感反馈时不强制震动。

## 布局

- [ ] 小屏/短屏/竖屏/横屏/分屏的关键操作均可达。
- [ ] 大字体可读，PIN/连接/键盘弹窗可滚动，确认/取消可达。
- [ ] 刘海、系统栏、手势导航和软键盘不遮挡。
- [ ] 触控目标至少 48dp，辅助功能可识别主要操作。

## 文字与中断

- [ ] 电视进入/退出输入框时手机界面正确打开/关闭。
- [ ] 手动关闭不反复弹；新焦点/重连重新初始化。
- [ ] 中文组字候选不发，只发提交文字；emoji 不被切断。
- [ ] 300ms 防抖保留最终文字、不重复追加。
- [ ] 编辑已发内容暂停自动同步，不擅自全量覆盖。
- [ ] 手动替换/清空符合明确意图。
- [ ] 断线、切设备/输入框、关弹窗、后台不把旧草稿写入新会话。
- [ ] 失败不盲目重放，恢复草稿前核对电视实际文字。

loopback、JVM 单测和仪器测试编译不能替代以上验证。首轮输入测试不用真实密码或敏感文字。
