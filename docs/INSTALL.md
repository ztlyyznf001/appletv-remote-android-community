# 安装、配对与排错

## 取得测试 APK

本公开快照尚未发布正式签名安装包。可按 [开发指南](DEVELOPMENT.md) 本地构建，或打开 Actions → Android CI → 成功运行 → Artifacts，下载 `android-debug-<run id>-<attempt>` 并解压 `app-debug.apk`。下载通常需要登录 GitHub，产物保留 7 天。

Actions 中的 `android-release-candidate-<run id>-<attempt>` 是供维护者复核来源和后续签名的构建产物。其中 `app-release-unsigned.apk` **未签名、不能直接安装**，不是已经发布的正式安装包。正式签名只在维护者私有环境完成。

需要 Android 8.0 及以上。系统若提示安装来源授权，只给打开 APK 的浏览器/文件管理器必要权限，完成后可关闭。不要安装来源不明的同名包。

当前源码应用 ID 为 `info.remote.appletv`，版本 `0.2.2` / code `7`。它描述源码，不表示本仓库已有正式 v0.2.2 Release。

### 签名冲突与数据

不同本地/CI debug 包可能有不同签名，Android 会拒绝覆盖。不要贸然卸载或清除数据，配对身份会丢失。当前没有配对导入/导出或跨签名迁移；确认能够重新配对并接受数据清除后，再安排更换安装。未来正式更新需要同一发布密钥和正确递增的版本号。

## 网络与配对

1. 手机和电视处于同一可互通局域网。电视可接网线；避免访客网络、客户端隔离或阻止局域网的 VPN/防火墙。
2. 唤醒电视，点击顶部设备区域，打开“附近的设备”。
3. 核对名称，选择目标 Apple TV。Companion 广播也可能来自其他 Apple 设备。
4. 点击“连接 / 配对”，输入电视当前显示的 4 位 PIN。
5. 等待加密会话建立，先验证方向、选择、返回、主屏幕和播放/暂停。

自动发现依赖 mDNS/Android NSD `_companion-link._tcp.`，能上网不等于设备之间可发现。不提供公网遥控，不要暴露电视端口到互联网。

PIN 只用于当前配对，不要发到聊天、Issues、截图或日志。设备地址和加密身份仅用于后续连接。

### 手动地址

在设备列表选择“手动填写地址和端口”。如果另一台 Android 手机可发现电视，可从它的设备列表读取相应 IPv4 和 Companion 端口，再填到当前手机。

端口不是固定值，电视重启/服务变化后可能更新。不要猜默认端口，也不要使用其他 Apple 服务端口。手动连接仍需 PIN 配对，不绕过身份验证。

## 触摸与文字

- 滑动移动焦点、轻点选择、长按 SELECT；也可切换方向键。
- 常用三键在竖屏底部/横屏侧边，音量和电源暂不提供。
- 支持的电视输入框出现时打开手机键盘，手动关闭后同一焦点不反复弹出。
- 中文候选/组字不发送，提交后经 300 ms 防抖追加；先用不敏感文字测试。
- 删除/修改已发文字会暂停自动同步。确实要覆盖整个电视输入框时才启用“手动替换电视全部文字”；空替换会清空输入框。
- 断线后不自动重发不确定是否送达的文字。核对电视后再恢复草稿，避免重复追加。
- 草稿仅在内存，关闭输入界面或后台会清理，不要作为重要文字唯一副本。

## 重连

回到应用只恢复上次成功配对的设备，每次前台最多尝试两次、间隔 3 秒。主动断开后暂停自动恢复，直到下次手动连接成功。不会自动发起陌生设备配对。

若旧身份被拒绝，先确认目标和地址，必要时移除保存的配对再输入新 PIN。不要公开存储文件或密钥排错。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 发现列表为空 | 同网、唤醒、组播/隔离限制，重试发现或手动地址 |
| 能看到却配不上 | 名称是否目标电视、当前 PIN、旧身份是否失效 |
| 卓易通发现失败 | 已有反馈为手动连接可用，仍需按实际系统版本验证 |
| 电视输入框没弹手机键盘 | 电视应用可能不暴露焦点/RTI 会话，基础遥控可能仍可用 |
| 手机删字电视没删 | 自动同步仅追加，核对后手动全量替换 |
| 发送成功电视无变化 | 协议无显示确认，以实际电视为准 |
| 安装签名冲突 | 先看迁移提醒，不要贸然卸载 |

普通问题按 [贡献指南](../CONTRIBUTING.md) 脱敏报告；安全问题见 [SECURITY](../SECURITY.md)。
